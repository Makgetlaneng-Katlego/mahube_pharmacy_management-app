# Mahube Pharmacy Management App

A student-built desktop application for managing pharmacy operations, built with C# and Windows Forms.

This project is a learning-focused application that explores desktop development, database design, and basic pharmacy workflows such as managing products, prescriptions, consultations, and user accounts.

> **Status:** In development. This is a college/learning project, not a production-ready pharmacy system.

---

## 📱 About the Project

Mahube Pharmacy Management App is a native Windows desktop application designed to simulate the internal management side of a pharmacy. It connects to a MySQL database and provides forms for staff to manage products, handle consultations, process prescriptions, and administer user accounts.

The goal is to practice building a complete desktop application: UI design, database connectivity, CRUD operations, and basic security considerations.

---

## ✨ Features

Based on the current repository structure, the app includes:

- **Product Management** – Add, update, delete, and export pharmacy products.
- **Order Management** – View and manage customer orders.
- **Consultation Management** – View consultations and send email responses to customers (via SMTP).
- **Prescription Management** – Handle prescription records.
- **User Management** – Manage system users and login credentials.
- **Login System** – Secure access to the application.
- **Database Integration** – MySQL database for persistent data storage.
- **Data Export** – Export product data to a separate view/table.
